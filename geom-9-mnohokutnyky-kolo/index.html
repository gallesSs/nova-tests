Многокутники й коло

πR²

Інтерактив: правильний n-кутник

Синє коло — описане (радіус R), зелене — вписане (радіус r).

1. Кути правильного многокутника

У правильного многокутника всі сторони рівні й усі кути рівні.

Сума кутів: 180° · (n − 2)
Один кут: α = 180° · (n − 2) / n
Зовнішній кут: 360° / n · центральний кут: 360° / n
Приклад: дев'ятикутник: α = 180° · 7 / 9 = 140°. Зовнішній кут — 360° / 9 = 40° (не плутай!).

2. Описане і вписане коло

Навколо будь-якого правильного многокутника можна описати коло і в нього можна вписати коло. Їхні центри збігаються.

R = a / (2 sin(180°/n)) · r = a / (2 tg(180°/n))
ФігураR (описане)r (вписане)Сторона через R
Трикутникa√3 / 3a√3 / 6a = R√3
Квадратa√2 / 2a / 2a = R√2
Шестикутникaa√3 / 2a = R

Для правильного трикутника R = 2r. Для шестикутника сторона дорівнює радіусу описаного кола — він складається з шести рівносторонніх трикутників.

3. Довжина кола і дуги

C = 2πR = πd
Дуга: l = πRα / 180°
Приклад: C = 8π см → d = C / π = 8 см.

4. Площа круга і сектора

S = πR²
Сектор: S = πR² · α / 360°
Приклад: R = 6 см, α = 60°: S = π · 36 · 60/360 = 6π см².

5. Площа правильного трикутника

S = a²√3 / 4
  1. Через R: a = R√3, тоді S = 3√3 R² / 4. Наприклад, R = 8: a = 8√3, S = 192·√3/4 = 48√3 см².
  2. Через r: R = 2r, a = 2√3 r, тоді S = 3√3 r². Наприклад, r = 4: S = 3√3 · 16 = 48√3 см².
