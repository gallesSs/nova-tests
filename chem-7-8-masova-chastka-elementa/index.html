Хімія · 7–8 клас · Склад речовини

Масова частка елемента

w(E), %

Відносна атомна і молекулярна маса

Ar — відносна атомна маса: у скільки разів атом важчий за 1/12 маси атома Карбону-12. Беремо з періодичної системи, округлюємо до цілих (крім Cl = 35,5).

Mr — відносна молекулярна (формульна) маса: сума Ar усіх атомів у формулі. Безрозмірна величина.

Mr(H2SO4) = 2·Ar(H) + Ar(S) + 4·Ar(O) = 2·1 + 32 + 4·16 = 98
Mr(Ca(OH)2) = 40 + 2·(16 + 1) = 74 — індекс за дужкою множить усе в дужках.

Масова частка елемента

Масова частка елемента w(E) — частка маси елемента в масі всієї речовини.

Формула
w(E) = n·Ar(E) / Mr · 100 %
n — кількість атомів елемента у формулі (індекс).
Перевірка
w₁ + w₂ + … = 100 %
Масова частка — від 0 до 1 (або від 0 до 100 %).
Задача. Обчисліть масові частки елементів у H2SO4.
Mr = 98.
w(H) = 2·1 / 98 · 100 % = 2,04 %
w(S) = 32 / 98 · 100 % = 32,65 %
w(O) = 4·16 / 98 · 100 % = 65,31 %
Перевірка: 2,04 + 32,65 + 65,31 = 100 % ✓

Типова помилка — забути індекс: у Fe2O3 маса Феруму 2·56 = 112, а не 56. Отже w(Fe) = 112/160 = 70 %.

Маса елемента в певній масі речовини

Пряма задача
m(E) = w(E) · m(речовини)
Обернена задача
m(речовини) = m(E) / w(E)
Скільки заліза можна добути з 320 г Fe2O3? w(Fe) = 0,7 → m(Fe) = 0,7 · 320 = 224 г.
Яка маса CaCO3 містить 20 г Кальцію? w(Ca) = 40/100 = 0,4 → m = 20 / 0,4 = 50 г.

Зручно й без w: у 160 г Fe₂O₃ (на одну «формулу») — 112 г Fe. Склади пропорцію 160 — 112, 320 — x.

Виведення формули за масовими частками

  1. Візьми 100 г речовини: тоді маси елементів у грамах дорівнюють їхнім відсоткам.
  2. Поділи масу кожного елемента на його Ar — отримаєш співвідношення кількості атомів.
  3. Поділи всі числа на найменше і, якщо треба, домнож до цілих.
  4. Якщо дано Mr (або густину газу), порівняй Mr найпростішої формули з істинною й домнож індекси.
w(S) = 50 %, решта — Оксиген. S : O = 50/32 : 50/16 = 1,5625 : 3,125 = 1 : 2 → SO2
w(C) = 85,7 %, w(H) = 14,3 %, Mr = 28. C : H = 85,7/12 : 14,3/1 = 7,14 : 14,3 = 1 : 2 → CH₂ (Mr = 14). 28 / 14 = 2 → C2H4

Кристалогідрати

Кристалогідрати містять воду в кристалах: мідний купорос CuSO4·5H2O, кристалічна сода Na2CO3·10H2O, гіпс CaSO4·2H2O.

Mr(CuSO₄·5H₂O) = 160 + 5·18 = 250. w(H₂O) = 90/250 · 100 % = 36 %
