Квадратні рівняння

D = b² − 4ac

Що таке квадратне рівняння

Загальний вигляд
ax² + bx + c = 0,  a ≠ 0
a — перший (старший) коефіцієнт, b — другий коефіцієнт, c — вільний член.
Рівнянняabc
3x² − 7x + 2 = 03−72
x² + 5x − 6 = 015−6
−x² + 4 = 0−104
2x² − 8x = 02−80

Коефіцієнти беремо разом зі знаком, який стоїть перед ними. Якщо при x² немає числа, то a = 1, якщо стоїть мінус — a = −1.

Дискримінант і корені

Дискримінант
D = b² − 4ac
Від латинського discriminare — «розрізняти»: за знаком D розрізняють, скільки коренів має рівняння.
D > 0
Два корені
x1,2 = (−b ± √D) / 2a
D = 0
Один корінь
x = −b / 2a
D < 0
Коренів немає
√ з від'ємного числа не існує

Приклад

  1. 2x² − 5x + 2 = 0: a = 2, b = −5, c = 2
  2. D = (−5)² − 4 · 2 · 2 = 25 − 16 = 9 > 0, √D = 3
  3. x1 = (5 + 3) / 4 = 2,   x2 = (5 − 3) / 4 = 0,5
  4. Відповідь: 0,5; 2

Алгоритм розв'язування

  1. Перенеси всі доданки в ліву частину, щоб справа був 0. Розкрий дужки і зведи подібні.
  2. Випиши a, b, c зі знаками.
  3. Обчисли D = b² − 4ac.
  4. За знаком D визнач кількість коренів і знайди їх.
  5. Перевір: підстав корінь у рівняння або скористайся теоремою Вієта.
x² = 7x − 10 → x² − 7x + 10 = 0 → D = 49 − 40 = 9 → x = 2 або x = 5

Неповні квадратні рівняння

Якщо b = 0 або c = 0, дискримінант не потрібен — так швидше.

ВиглядЯк розв'язатиПриклад
ax² + bx = 0Винеси x: x(ax + b) = 0, тоді x = 0 або x = −b/a. Завжди два корені.3x² − 12x = 0 → 0; 4

Типові помилки

  • Знак b. У рівнянні x² − 6x + 5 = 0 b = −6, а b² = (−6)² = 36, а не −36. Квадрат завжди невід'ємний.
  • Мінус на мінус. Якщо c < 0, то −4ac стає додатним: для x² + 2x − 8 = 0 D = 4 + 32 = 36.
  • Ділити на 2a, а не на 2. Для 3x² ділимо на 6.
  • Забули перенести все вліво. Спершу рівняння має виглядати як ax² + bx + c = 0.
  • Мінус перед −b. Якщо b = −5, то −b = 5.

Перевірка за теоремою Вієта

x1 + x2 = −b / a x1 · x2 = c / a

Для x² − 7x + 10 = 0 корені 2 і 5: 2 + 5 = 7 = −(−7), 2 · 5 = 10 = c. Збігається — отже, розв'язано правильно.
