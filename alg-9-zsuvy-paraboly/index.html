Зсуви параболи

y = (x − m)² + n

Конструктор параболи

Рухай повзунки й дивись, як парабола y = x² (пунктир) зсувається, перевертається й розтягується.

1. Зсув уздовж осі Oy: y = x² + n

Кожна точка параболи піднімається на n одиниць (якщо n > 0) або опускається (якщо n < 0). Вершина переходить у точку (0; n).

y = x² + 3 — на 3 вгору, вершина (0; 3). y = x² − 5 — на 5 вниз, вершина (0; −5).

2. Зсув уздовж осі Ox: y = (x − m)²

Парабола зсувається вправо на m, якщо m > 0, і вліво — якщо m < 0. Вершина — (m; 0).

ПасткаЗнак «навпаки»: y = (x − 3)² — вправо на 3, а y = (x + 3)² — вліво на 3, бо x + 3 = x − (−3), тобто m = −3.

Як перевірити: вершина там, де дужка дорівнює нулю. (x + 3)² = 0 при x = −3.

3. Обидва зсуви: y = (x − m)² + n

Спершу зсув на m уздовж Ox, потім на n уздовж Oy. Вершина параболи — (m; n), вісь симетрії — пряма x = m.

Приклад: y = (x − 4)² − 4. Вершина (4; −4): графік y = x² зсуваємо на 4 вправо й на 4 вниз.

4. Знак і коефіцієнт a: y = a(x − m)² + n

  • a > 0 — вітки вгору, a < 0 — вітки вниз (парабола перевернута: y = −x²).
  • |a| > 1 — парабола «вужча» (крутіша), 0 < |a| < 1 — «ширша».
  • Від вершини: на 1 вбік — на |a| вгору/вниз, на 2 вбік — на 4|a|, на 3 вбік — на 9|a|.

5. Як читати властивості з графіка

На прикладі y = (x − 4)² − 4:

  1. Нулі функції — де графік перетинає Ox: (x − 4)² = 4 → x − 4 = ±2 → x = 2, x = 6.
  2. Від'ємні значення — де графік нижче Ox: x ∈ (2; 6).
  3. Спадає до вершини: (−∞; 4], зростає після: [4; +∞).
  4. Область значень — від вершини вгору: [−4; +∞).

Для a < 0 усе навпаки: спершу зростає, потім спадає, а область значень — (−∞; n].
